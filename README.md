# Python To-Do List Task Manager

A command-line To-Do List application built with Python for creating, managing, and tracking tasks.

## Features

- Add new tasks
- View existing tasks
- Mark tasks as completed
- Delete tasks
- Persistent task storage
- Input validation
- Simple command-line interface

## Project Structure

- `main.py` — Application entry point
- `tasks.py` — Task management logic
- `storage.py` — Persistent data storage
- `ui.py` — User interface and input handling

## Technologies

- Python
- JSON
- File Handling

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python main.py
